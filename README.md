# AviatorDemoSignal

An Android mobile application project for **Aviator Demo Signal**.

## Project Overview
This repository contains the Android mobile build setup and project files for `AviatorDemoSignal`.

## Repository Contents
- `AviatorDemoSignal-MobileBuild...` — Mobile build directory/files
- `README MOBILE BUILD.md` — Mobile build instructions and notes
- `build.gradle` — Root/project Gradle build configuration
- `gradle.properties` — Gradle runtime and project properties
- `settings.gradle` — Project module and repository settings

## Getting Started (Android Studio)
1. Clone or download the repository to your local machine.
2. Open the project folder in **Android Studio**.
3. Allow Gradle to sync dependencies and index the project.
4. Build and run the project on an emulator or physical Android device.

## Disclaimer
This project is a demo/simulation setup for testing and development purposes only.

# Aviator Demo Signal

This is a demo-only Android app. Signals are randomly generated examples and do not predict real Aviator outcomes.

## Build an APK using only your Android phone (cloud build)
1. Sign in to GitHub in your phone browser and create a **new public repository**.
2. Extract this ZIP on your phone.
3. Upload all project files and folders to the repository. Make sure `.github/workflows/build-apk.yml` is included.
4. Open the repository's **Actions** tab and select **Build Android APK**.
5. Tap **Run workflow** (or wait for the first upload-triggered build).
6. When the run finishes successfully, open the run, find **Artifacts**, and download `Aviator-Demo-Signal-APK`.
7. Extract the downloaded artifact ZIP. Tap `app-debug.apk` to install. Android may ask permission to install unknown apps; only proceed if you trust the file you built.

No betting prediction is provided. The displayed signals are random demo samples only.
